# Papers

Paper-style documents that explain how LeanElpi works and why, written for Lean users new to λProlog and ELPI users new to Lean. Read them in order or start from the topic you need.

- [[system]] — LeanElpi: Embedding Lambda Prolog in Lean 4, an overview of the whole system with a worked tour
- [[type-bridge]] — Plain Types and Independent Types, how ELPI's simple types and Lean's dependent types meet
- [[engine]] — A Persistent Abstract Machine for Lambda Prolog, unification, resolution, backtracking and constraints
- [[solvers]] — Writing Your Own Solver, the four solver tiers with worked examples
- [[lean-together]] — Using Lean and ELPI Together, commands, tactics, the runtime library and binaries
- [[certified-lf]] — Certified Proof Search with LF, the dependent extension and kernel-checked certificates
